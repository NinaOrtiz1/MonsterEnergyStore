# MONSTER ENERGY STORE

## Descripción

MonsterEnergyStore es un proyecto académico para una página web promocional de una tienda ficticia especializada en bebidas Monster Energy. Su propósito es presentar la tienda y ofrecer un punto de partida para organizar su información.

## Objetivo

Desarrollar una página web sencilla que presente la tienda y sus bebidas de manera clara y accesible.

## Tecnologías

- HTML5
- CSS3
